# 🛍️ Integrating into Shopify Liquid Themes

This guide details how to turn these sections into modular, customizable Shopify Sections in Online Store 2.0 themes (Dawn, Prestige, Impulse, etc.).

---

## 1. Upload Assets to Shopify

1. In your Shopify Admin, go to **Content** → **Files**.
2. Upload the images from `assets/img/hero/`, `assets/img/funnels/`, `assets/img/team/`, etc.
3. Note the CDN URLs generated by Shopify (e.g. `https://cdn.shopify.com/s/files/1/.../f8.webp`).
4. Alternatively, in your theme code editor, upload CSS and JS files to the **Assets** folder:
   - `assets/ftp-sections.css`
   - `assets/ftp-opening.js`
   - `assets/ftp-portfolio.js`

---

## 2. Create Custom Liquid Sections

### A. Opening Hero Section (`sections/ftp-hero.liquid`):
Create a file `sections/ftp-hero.liquid` in your theme:
```liquid
{{ 'ftp-sections.css' | asset_url | stylesheet_tag }}

<header class="hero" id="top">
  <video class="hbg" autoplay muted loop playsinline aria-hidden="true">
    <source src="{{ section.settings.bg_video_url }}" type="video/mp4">
  </video>

  <div class="box">
    <h1 class="h1 d rise">
      {{ section.settings.headline }}
      <span class="type" id="type">{{ section.settings.typewriter_text }}</span>
    </h1>

    <p class="lead hl" id="hlead">
      {{ section.settings.subheading }}
    </p>

    <div class="hcta rise">
      <a class="btn grad" href="{{ section.settings.cta_link }}">
        {{ section.settings.cta_text }} <i>&#8599;</i>
      </a>
    </div>

    <!-- Floating 3D Stage -->
    <div class="stage" id="stage">
      <div class="agent rise">
        <video poster="{{ 'agent.webp' | file_url }}" autoplay muted loop playsinline>
          <source src="{{ 'agent.mp4' | file_url }}" type="video/mp4">
        </video>
      </div>
      <!-- Rest of stage elements from vanilla-html/opening.html -->
    </div>
  </div>
</header>

<script src="{{ 'ftp-opening.js' | asset_url }}" defer></script>

{% schema %}
{
  "name": "FTP Opening Hero",
  "settings": [
    { "type": "text", "id": "headline", "label": "Headline", "default": "We build funnels that print" },
    { "type": "text", "id": "typewriter_text", "label": "Initial Typewriter Word", "default": "booked calls." },
    { "type": "textarea", "id": "subheading", "label": "Subheading", "default": "Define the offer, connect your traffic, and let the funnel do the work." },
    { "type": "text", "id": "cta_text", "label": "CTA Text", "default": "Build my funnel" },
    { "type": "url", "id": "cta_link", "label": "CTA Link" },
    { "type": "text", "id": "bg_video_url", "label": "Background Video URL" }
  ],
  "presets": [
    { "name": "FTP Opening Hero" }
  ]
}
{% endschema %}
```

---

## 3. Adding to your Store Pages

1. Open Shopify **Theme Customizer**.
2. Click **Add section**.
3. Choose **FTP Opening Hero** or **FTP iPhone Duo Portfolio**.
4. Configure your headlines, CTA links, and media in the Shopify sidebar!
