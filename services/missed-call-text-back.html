FAQ

Missed Call Text Back questions

What is missed call text back?+

An automation that sends an SMS to anyone whose call you miss, so the conversation continues by text instead of ending at voicemail.

Do I need A2P 10DLC registration?+

In the US, business texting from a local number needs A2P 10DLC registration. We handle it as part of the setup. See our A2P 10DLC guide for details.

Can it book appointments automatically?+

Yes. The text can include a booking link, and an optional AI assistant can reply and book for you.

Which CRM does this run on?+

We usually set it up in GoHighLevel, where calls, texts and the pipeline live together.
